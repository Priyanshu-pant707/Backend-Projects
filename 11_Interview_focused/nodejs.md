# Interview questions :

1. what do you mean by asynchronous API ?
- An asynchronous api is a non blocking api that allows node.js to continue executing other tasks without waiting for an operation to complete .
- when an asynchronous function is called , Node.js registers the operation and immediately moves to the next task. once the operation finishes,  a callback function , promise , or async/await mechanism is used to handle the result.


2.  what are the benefits of using node.js ?
- node.js offers several advantages that make it a popular choice for modern web applications :
 1. Asynchronous and event driven
 2. Very fast execution
 3. single threaded but highly scalable
 4. no buffering
 5. javascript everywhere
 6. Large ecosystem
 7. ideal for real-time applications
 8. cross platform development
