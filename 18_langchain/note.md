# Langchain :

- it is an open-source framework for building applications powered by large language models (llms).
- it helps developers connect ai model to external data tools, apis, databases and workflows making it easier to create sophisticated beyond simple chatbots.


# what langchain provides :
1. Prompt management
2. Chains
3. Agents
4. Agents
5. Rag
6. Memory
7. Tool integration 


## typical use cases 
1. Ai chatbots
2. Document question-answering system
3. Customer support assistants
4. Research assistants
5. Data analysis workflows
6. Autonomous Ai agents
