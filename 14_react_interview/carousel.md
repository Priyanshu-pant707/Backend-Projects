# Carousel :
- a carousel is a UI component that displays a collection of items one at a time or few at a time , allowing users to navigate through them :

-example :
  - netflix movie slider
  - amazon product slider
  - instagram story previews
  - hero banners on websites



#  what is export default ?
- it is used to export one main value (component,function,class,object) from  a file so that other files can import it.

# intution to building the crousel 
- i stored the current slide index in React state using useState . Clicking next or previous updates the index, and the image is rendered using image[currentIndex].

# what is memory leak :

- resources such as intervals , timers , subscriptions, or even listeners continue running after the component is removed .
